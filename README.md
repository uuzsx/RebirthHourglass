Rebirth Hourglass / 重生沙漏 — Minecraft 26.4 待适配分支

**此分支尚不支持 Minecraft 26.4，没有可安装的模组 JAR。**

截至 2026-09-24，Minecraft 官方版本清单中的最新正式版为 26.3，26.4 仅有 `26.4-snapshot-1`。NeoForge 官方 Maven 版本清单中没有 26.4 对应构建，因此尚无法编译、运行或验证 NeoForge 26.4 模组。

此分支按项目版本规划预留，仅保存状态说明。上游依赖发布后，再从最近的已验证版本移植，完成构建、单元测试、死亡恢复与传送的服务端 GameTest，之后才提供安装包。

主要维护版本仍为 [`main` / Minecraft 1.21.1](https://github.com/uuzsx/RebirthHourglass/tree/main)。其他分支：
